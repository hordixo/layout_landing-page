# Bang & Olufsen Landing Page

This project is a landing page dedicated to Bang & Olufsen products — a premium brand known for high-quality audio equipment and elegant design.

## 🔥 About the project
The landing page presents Bang & Olufsen products, their style, and brand philosophy.  
The goal of this project is to practice HTML, SCSS, and responsive layout skills.

## 🛠 Technologies used
- HTML5
- SCSS (Sass)
- BEM methodology
- Responsive layout (Flexbox/Grid)
